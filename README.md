# consulo.dev

Consulo Plugin Development Documentation, built with [VitePress](https://vitepress.dev/).

## Requirements

* Node.js 20+

## Setup

```bash
npm install
```

## Development

Start a local dev server with hot reload:

```bash
npm run docs:dev
```

## Build

Build the static site:

```bash
npm run docs:build
```

## Preview

Preview the built site locally:

```bash
npm run docs:preview
```
